# Django RQL
Django Project Creator is a Python script designed to streamline the creation of Django projects. When executed, the script prompts the user for specific inputs and uses these inputs to automatically generate a Django project. This tool is ideal for developers who want to quickly set up a new Django project with custom configurations.


# Clone the repository
```bash
git clone git@github.com:Quokka-Labs-LLP/base-django-auto-script.git
```

# Navigate to the project directory
```bash
cd base-django-auto-script
```

# Run the python script
```bash
python auto-django.py
```
# Installation
Input the details asked during the execution of script during the execution of the file.

# Clean up
After installation delete the .git file.
